# APEX_TASK_01
# Basics of Web Development

## 📌 Project Overview
This project was created as part of **Task 1** of the **Web Development Internship** at ApexPlanet Software Pvt. Ltd.

The objective of this task was to learn and apply the foundational concepts of HTML, CSS, and JavaScript by building a simple interactive webpage.

---

## 🎯 Objectives

- Understand the basic structure of an HTML document.
- Apply CSS styling to improve the appearance of a webpage.
- Add basic interactivity using JavaScript.
- Create a responsive and visually appealing user interface.

---

## 🚀 Features

### HTML
- Semantic page structure
- Headings and paragraphs
- Images and links

### CSS
- Custom styling
- Card-based layout
- Background image
- Responsive design
- Hover effects
- Glassmorphism-inspired card design

### JavaScript
- Interactive button
- Alert message on button click

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
